# Security policy

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub (GitHub Private
Vulnerability Reporting):

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.

Do not open a public issue, pull request or discussion for a vulnerability.

Give as much of this information as you can: the affected version or commit,
the component (portal, Windows agent, Docker image), the steps to reproduce the
problem and the impact that you expect.

## Supported versions

Only the latest release gets security fixes. This includes the newest tag of
the Docker image `docker.io/lostindreamz/nodiverna`. Update to the latest
release before you report a problem.

## Response

We try to answer each report in 7 days or less. We tell you if we can
reproduce the problem and how we plan to repair it. We keep you informed until
we release the fix.
